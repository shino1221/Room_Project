SafeRoom 개발 지침

코드 작성
- 코드는 직관적으로 작성하고, 복잡한 계산이나 처리에는 필요한 주석을 단다.
- 기능과 처리 단계별로 줄바꿈하고 관련 코드를 가까이 모은다.
- 변수명과 함수명은 역할을 알아볼 수 있게 작성한다.
- 파일은 기능에 따라 나누되, 작고 밀접한 기능은 함께 둔다.
- 불필요한 파일과 함수를 만들지 않고, 공통 로직은 재사용한다.

데이터와 기능
- API 키는 코드에 직접 쓰지 않고 환경변수로 관리한다.
- 데이터 없음, 조회 실패, 사용자 미확인을 구분해 표시한다.
- 필수 정보가 부족하면 점수를 보류하고, 확인된 위험 항목은 바로 표시한다.
- 매물별 방문·계약 기록을 저장하고 다시 확인할 수 있게 한다.
- 등록부터 조회·기록·비교까지 점검하고 자료 부족과 API 오류도 확인한다.

UI와 디자인
- CSS와 화면을 간결하게 구성하고 정보와 기능을 쉽게 찾을 수 있게 한다.
- 과도한 장식과 반복 문구를 줄이고 자연스러운 표현을 쓴다.
- 스마트폰에서 매물 조회와 방문 체크리스트를 편하게 사용할 수 있게 한다.

개발 범위
- 대학 과제 수준에서 핵심 기능이 동작하도록 구현한다.
- 새 기능이나 구조는 필요성을 먼저 판단하고 불필요한 복잡성을 줄인다.
